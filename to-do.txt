Key file details (what to put where)

embeddings/preprocess.py:
face detection (MTCNN / dlib / RetinaFace), crop & align faces
image normalization, size resizing (e.g., 112×112 or 160×160)
embeddings/models.py:
wrapper class EmbeddingModel(backend, device) with encode(batch_images) returning L2-normalized vectors
support pluggable backends: PyTorch model, ONNX, or remote API (Replicate, cloud)
vector_db/faiss_adapter.py:
build index (IndexFlatIP / IndexIVFFlat) with metadata mapping (id -> filename, person_id)
functions: create_index, upsert(embeddings, metadata), search(query_embedding, k)
api/main.py:
small FastAPI app with endpoints:
POST /ingest accepts image(s), returns assigned ids
POST /search accepts image or embedding, returns top-k matches and distances
GET /status health
tools/index_dataset.py:
pipeline: preprocess -> encode -> upsert to vector DB -> store metadata (SQLite / JSONL)
docs/:
architecture.md (embedding flow, index choices)
quickstart.md (how to run local FAISS demo)
tuning.md (index parameters, accuracy vs latency)
